
# Student Record Management System

A console-based Student Record Management System built using Java.

## Features
- Add student records
- View all students
- Search students by roll number
- Update student marks
- Delete student records
- Calculate grades based on marks

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList

## How to Run
1. Compile the program:
   javac Main.java

2. Run the program:
   java Main
